# BugRowSum　行ごとの合計（第5回）

ソース: [row_sum.c](row_sum.c)

## 対象の回と前提

- 第5回（配列と関数）。課題2 `ColumnSum`（列ごとの合計）の後。二次元配列と二重ループの組み合わせ。
- 学生が知っていること: 二次元配列 `table[行][列]`，二重の `for`，`enum` の定数，第4回のブレークポイント（F9）・F5・F10・**Locals**。
- 入力も引数もない。

## プログラムがするはずのこと

3 行 3 列の表 `{{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}` の行ごとの合計を表示する。期待する表示:

```text
row 0: 6
row 1: 15
row 2: 24
```

## 症状

**Startup Item** で `debugging BugRowSum` を選び，Ctrl+F5 で実行する。

```text
row 0: 6
row 1: 21
row 2: 45
```

最初の行だけ正しく，2 行目からずれる（テスト `debugging/BugRowSum/symptom`）。

## 学生への渡し方

- 渡すもの: `row_sum.c` だけ。
- 最初に言うこと: 「3 行 3 列の表の行ごとの合計を出すプログラムです。`row 0: 6`，`row 1: 15`，`row 2: 24` と出るはずですが，Ctrl+F5 で実行すると 6，21，45 と出ます。原因をデバッガで探してください」
- 言わないこと: `sum` の宣言の位置。

## 探し方

1. **症状から範囲を絞る**: 1 行目は正しい。2 行目の 21 は 6 + 15，3 行目の 45 は 6 + 15 + 24。「前の行の合計が残っているのでは」と気付けば，仮説まで一気に進む。気付かなければ次へ。
2. **境目で止める**: 内側のループの `sum += table[row][col];` の行に F9 を置き，F5。**Locals** で `row`・`col`・`sum` を見ながら F5（**Debug > Continue**）で進める。
3. `row` が 1，`col` が 0 で止まったときの `sum` を見る。2 行目を足し始める前なので 0 のはずが，6 になっている。
4. **仮説**: 「`sum` を 0 にするのはループの前の 1 回だけで，行が変わっても 0 に戻していない」。
5. **確かめる**: `sum` に 0 を代入している行がどこにあり，外側のループの何回目に実行されるかを答えさせる（ループの外なので 1 回だけ）。

## ヒントの段階

1. 「21 は 15 と比べていくつ多い？ 45 は 24 と比べて？」
2. 「2 行目を足し始める直前（`row` が 1，`col` が 0）で止めて，`sum` を見よう」
3. 「`sum` を 0 にしているのはどの行？ その行は何回実行される？」

## 原因

累積する変数 `sum` を外側のループの**前**で 1 回だけ 0 にしているので，2 行目以降は前の行までの合計に足し続ける。行ごとの合計なら，外側のループの本体の先頭（内側のループの前）で毎回 0 にする（第4回 講義 7 節の表「累積変数の初期化位置」，第5回の `ColumnSum` の `int sum = 0;  // 列が変わるたびに 0 から数え直す`）。
コンパイラは警告を出さない（`sum` は初期化してから使っており，文法上の誤りはない）。

## 直し方

```diff
-    int sum = 0;
-
     for (int row = 0; row < ROWS; ++row) {
+        int sum = 0;
         for (int col = 0; col < COLS; ++col) {
```

直した版は `6`・`15`・`24` を表示する（テスト `variant_fixed`）。宣言ごと外側のループの中へ移すと，`sum` のスコープが 1 行分に限られ，行をまたいで使う誤りも起きなくなる。

## 学生への問い

- 問「表が 1 行だけだったら気付けた？」→ 気付けない。1 行目は正しいので，2 行以上で試す必要がある（繰り返しは 0 回・1 回・複数回で試す）。
- 問「0 にする場所を内側のループの本体にしたらどうなる？」→ 宣言ごと移すと，内側のループの外にある `printf` から `sum` が見えなくなり，コンパイルエラーになる。宣言は外に残して `sum = 0;` の代入だけを移すと，列ごとに 0 に戻るので，各行の最後の要素（3，6，9）だけが表示される。「どのループの何回ごとに数え直すか」で置く場所が決まる。
- 問「この誤りを 1 文で書くと？」→ 「行ごとの合計なのに，`sum` を行が変わるたびに 0 に戻していなかった」。
