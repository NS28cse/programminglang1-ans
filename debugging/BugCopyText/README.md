# BugCopyText　文字列をコピーする（第8回）

ソース: [copy_text.c](copy_text.c)

## 対象の回と前提

- 第8回（ポインタ1）。講義 4 節「コピーの代入式を読む」と，課題3 `CopyText`（安全な文字列コピー）の後。
- 学生が知っていること: ポインタの `*` と `++`，文字列の終端 `'\0'`，ブレークポイント（F9）・F5・F10・**Locals**。
  関数の中へ入るステップイン（F11）と **Watch 1** は授業では未習（実務の手引きの第8回で先取りして見せる操作）。
- 入力も引数もない。

## プログラムがするはずのこと

`copy_text(dst, src)` は `src` の文字列を終端まで `dst` へコピーする。同じ配列 `buffer` へ `"horse"`，`"cat"` の順にコピーし，そのたびに `buffer` を表示する。期待する表示:

```text
horse
cat
```

## 症状

**Startup Item** で `debugging BugCopyText` を選び，Ctrl+F5 で実行する。

```text
horse
catse
```

1 回目は正しく，2 回目に前の文字列の残り `se` が付く（テスト `debugging/BugCopyText/symptom`）。

## 学生への渡し方

- 渡すもの: `copy_text.c` だけ。
- 最初に言うこと: 「文字列をコピーする関数 `copy_text` で，同じ配列へ `horse`，`cat` の順にコピーして表示します。`horse`，`cat` と出るはずですが，Ctrl+F5 で実行すると `horse`，`catse` と出ます。原因をデバッガで探してください」
- 言わないこと: 終端のコピー。

## 探し方

1. **症状を読む**: `catse` は `cat` と `horse` の 4・5 文字目の `se`。「`cat` は上書きされたが，`horse` の残りが消えていない」と言葉にさせる。
2. **2 回目のコピーの後で止める**: 2 つ目の `printf("%s\n", buffer);` の行に F9，F5。**Locals** の `buffer` を展開して `[0]`〜`[5]` を見る: `'c' 'a' 't' 's' 'e' '\0'`。`[3]` が `'\0'` ではない。
3. **仮説**: 「`copy_text` は文字をコピーするが，終端 `'\0'` をコピーしていない。1 回目は `buffer` がもともと全部 0 だったので正しく見えただけ」。
4. **確かめる**: 1 つ目の `copy_text(buffer, "horse");` の行で止め，F11（**Debug > Step Into**。授業では未習）で `copy_text` に入る。**Debug > Windows > Watch > Watch 1**（授業では未習）に `*src` と `*dst` を書き，F10 で進める。`*src` が `0 '\0'` になったところで `while` を抜け，`'\0'` を `*dst` へ書く文を通らないことを見る。
   F11 を使わない場合は，`copy_text` の `while` の行に F9 を置いて F5 で止め，**Locals** の `src` の右に出る文字（`0x... "e"` → `0x... ""`）で同じことを確かめる。

## ヒントの段階

1. 「2 回目のコピーの後，`buffer[3]` には何が入っている？ `cat` で終わるには何が入っているべき？」
2. 「1 回目は正しく見えたのはなぜ？ `buffer` は最初どう初期化されていた？」
3. 「`copy_text` のループは，`*src` が `'\0'` のときにも `*dst` へ代入する？」

## 原因

ループの条件 `*src != '\0'` が偽になった時点でループを抜けるので，終端の `'\0'` を `dst` へ書かない。
1 回目は `buffer` が `""` で初期化され（残りの要素も 0），`horse` の後ろがたまたま `'\0'` だったので正しく見える。2 回目は `horse` の 4 文字目以降が残り，`%s` は次の `'\0'`（`buffer[5]`）まで表示する。
`buffer` が初期化されていない配列なら，残りの値は決まらず，配列の外まで読むおそれもある。

## 直し方

ループの後で終端を書く。

```diff
         ++src;
     }
+    *dst = '\0';
 }
```

直した版は `horse`・`cat` を表示する（テスト `variant_fixed`）。講義 4 節の `while ((*dst = *src) != '\0')` の形は，代入してから比べるので終端もコピーしてから止まる（第8回 課題3 `CopyText` の本体と同じ）。

## 学生への問い

- 問「1 回のコピーだけでテストしていたら気付けた？」→ 気付けない（コピー先が 0 で初期化されていれば正しく見える）。コピー先に別の文字が入っている状態（演習の `"aaaaaaaaaa"` へ `"hoge"`）で試す。
- 問「`"cat"` を 4 要素の配列にコピーするとき，`copy_text` は何回代入するべき？」→ 4 回（`c`・`a`・`t`・`'\0'`）。
- 問「`strcpy` ならこの誤りは起きない？」→ 起きない（終端までコピーする）。ただし容量を確かめないので，`CopyText` のように容量を調べてから使う。
