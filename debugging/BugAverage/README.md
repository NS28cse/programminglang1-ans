# BugAverage　平均点（第6回）

ソース: [average.c](average.c)

## 対象の回と前提

- 第6回（文字列）。講義 5 節「数値の型変換」の「代入先の型が大きくても，計算は先に終わる」と，課題3 `Average`（変換する順序）の後。
- 学生が知っていること: 整数の割り算は小数部を切り捨てること（第3回），暗黙の型変換・キャスト，配列，ブレークポイント（F9）・F5・F10・**Locals**。
- 入力も引数もない。

## プログラムがするはずのこと

5 人の点数 `{72, 85, 60, 93, 81}` の合計と平均（小数第 1 位まで）を表示する。期待する表示:

```text
total=391 mean=78.2
```

## 症状

**Startup Item** で `debugging BugAverage` を選び，Ctrl+F5 で実行する。

```text
total=391 mean=78.0
```

合計は正しく，平均の小数部が 0 になる（テスト `debugging/BugAverage/symptom`）。

## 学生への渡し方

- 渡すもの: `average.c` だけ。
- 最初に言うこと: 「合計 391 を 5 人で割ると 78.2 のはずですが，78.0 と出ます。`mean` に代入された直後の値を確かめてください」
- 言わないこと: 整数除算・キャスト。

## 探し方

1. **範囲を絞る**: 合計 391 は正しいので，誤りは合計の後（平均の計算か表示）にある。
2. **値を見る**: `printf` の行に F9 を置き，F5。**Locals** の `mean` が `78.000000000000000` であることを見る。表示（`%.1f`）ではなく，代入された時点で小数部がない。
3. **仮説**: 「`total / COUNT` が `int` 同士の割り算で 78 になり，それが `double` に変換されて 78.0 になる。`double` の変数に入れても，割り算は代入の前に終わっている」。
4. **確かめる**: `double mean = total / COUNT;` の右辺の 2 つの型を言わせる（どちらも `int`）。**Debug > Windows > Watch > Watch 1**（授業では未習。第13回の演習で使う）に `total / COUNT` と `total / 5.0` を書いて，78 と 78.200000000000003（`double` の表示）が並ぶことを見せてもよい。

## ヒントの段階

1. 「`mean` に入った直後の値は 78.2？ それとも 78.0？」
2. 「`total / COUNT` の 2 つの値の型は？ その割り算の結果の型は？」
3. 「`double` の変数に代入するのは，割り算の前？ 後？」

## 原因

`total`（`int`）÷ `COUNT`（`int` の定数）は整数の割り算で，小数部を切り捨てた 78 になる。その 78 が代入のときに `double` へ変換されて 78.0 になる。
代入先の型は右辺の計算の型を変えない（講義 5 節「代入先の型が大きくても，計算は先に終わる」）。`int` から `double` への変換は値を失わないので，MSVC `/W4` でも GCC・Clang でも警告は出ない。

## 直し方

割る前に片方を `double` にする。

```diff
-    double mean = total / COUNT;
+    double mean = (double)total / COUNT;
```

直した版は `total=391 mean=78.2` を表示する（テスト `variant_fixed`）。`(double)(total / COUNT)` では割り算の後に変換するので直らない。

## 学生への問い

- 問「点数が `{70, 80, 90, 60, 100}` だったら気付けた？」→ 気付けない。合計 400 は 5 で割り切れるので，誤りの版も 80.0 になる。割り切れない入力で試す。
- 問「`(double)(total / COUNT)` ではなぜ直らない？」→ 括弧の中の整数の割り算が先に終わり，切り捨てた 78 を `double` にするだけだから。
- 問「`total / 5.0` でも直る。`(double)total / COUNT` との違いは？」→ 結果は同じ。`5.0` と書くと人数を 2 か所に書くことになるので，`COUNT` を使う方が人数を変えたときに直し忘れがない。
